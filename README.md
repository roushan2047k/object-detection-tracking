# Object Detection and Tracking

A Python project that detects and tracks objects using OpenCV
and the MobileNet-SSD pretrained model.

## Features
- Real-time webcam detection
- Object labels and bounding boxes
- Confidence scores
- Basic object tracking IDs

## Requirements
- Python
- OpenCV

## Run the Project

Install the dependency:

pip install opencv-python

Run the program:

python object_tracking.py
